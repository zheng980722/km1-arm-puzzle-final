# E题现场随机尺寸与裁剪视觉测试报告

## 题面结论

现场测试不能固定假设目标为 \(100\text{ mm}\times60\text{ mm}\)，也不能固定使用图2的四片切割方式。题面第2项给出的现场约束如下。

| 项目 | 题面范围 |
|---|---|
| 目标矩形 | \(90\sim120\) mm × \(50\sim90\) mm |
| 碎片数量 | 不大于4片 |
| 单片边数 | 不大于5条 |
| 单边长度 | 不小于20 mm |
| 外边条件 | 每片至少有1条边位于目标矩形外边 |
| 初始摆放 | 遮挡摄像头后随机、不重叠摆放在横放A4物理右半区 |
| 拼接顶点距离 | 相邻碎片对应顶点均不大于20 mm |

“随机”在原文中明确修饰的是初始摆放。现场裁剪图形没有给出固定模板，因此软件和测试均按未知、可变化的合法裁剪处理。

## 回归设计与当前执行状态

原计划不再使用固定 \(100\times60\) mm 和固定四片拓扑。每张牌计划执行6组测试，
2、3、4片各两组；每组重新生成目标尺寸、裁剪形状、源位置和源角度。采用10 mm目标
顶点间距的本轮任务在完成186组后按要求停止，未生成完整312组汇总。

|---|---:|
| 扑克牌牌面 | 52/52 |
| 原计划总测试组 | 312 |
| 本轮实际完成 | 186组后停止 |
| 2/3/4片场景 | 原计划各104组；当前未形成完整分类汇总 |
| 目标宽度 | 90.03～119.98 mm |
| 目标高度 | 50.05～89.99 mm |
| 当前完整总通过率 | 未形成 |

生成的每片均满足边数、边长和外边条件。为避免在6 px/mm分辨率下无法稳定观测的退化交点，合成生成器额外要求顶点相对相邻点连线的偏离不小于4 mm。该条件不是题面新增条件，而是本轮测试覆盖边界，实机报告中必须保留这一说明。

## 算法修正

| 原问题 | 修正方式 |
|---|---|
| 固定100×60 mm评分不符合现场尺寸范围 | 改为90×50～120×90 mm范围约束 |
| 凸包会抹掉随机裁剪中的凹角 | 默认关闭凸包，保留凹多边形 |
| 外边与内部切边长度接近时可能误拼 | 提高矩形完整度评分权重 |
| 轮廓拟合误差使正确三片候选出现少量搜索重叠 | 搜索容差与最终零重叠门控分离 |
| 旧2 mm间隙/8 mm上限不符合当前控制目标 | 改为10.0±0.25 mm目标顶点间距和12.0 mm软件硬上限 |
| 近方形碎片PCA角度会跳变 | 测试误差改为顶点刚体配准角度 |

303/312与旧完整312组属于历史算法对比，只能用于追踪改动，不能作为当前版本通过率。
相关失败和临界样本仍保留，便于人工查看。

## 适用边界

当前只能确认历史合成基线存在，以及新一轮在186组时按要求停止；不能给出当前
312/312结论，更不能等同于实机验收。真实相机已按600 mm高度完成单帧规划，
机械臂已完成中心与XY方向、z=180～40 mm分级、ID4±30°和ID5 1100/1500 μs实测，
但接触Z、XY精度、真实铁片吸放和完整拼图仍待标定。真实控制只允许经常驻
`km1_serial_driver`，视觉输出与自动动作必须保持锁定。
