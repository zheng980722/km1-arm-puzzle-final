# 扑克牌演示模板来源

演示模板选自 `hayeah/playing-cards-assets`：

https://github.com/hayeah/playing-cards-assets

该项目说明原始牌面素材来自公共领域的 vector-playing-cards，并为仓库中的处理版本提供 MIT License。下载脚本会同时保存上游 `LICENSE`。

默认下载完整52张牌面。以下四张可作为快速调试代表：

| 文件 | 测试价值 |
|---|---|
| `ace_of_spades.png` | 大面积黑色图案和空白区域 |
| `10_of_diamonds.png` | 多个重复红色点数图案 |
| `queen_of_hearts.png` | 复杂人像、红黑混合纹理 |
| `king_of_clubs.png` | 复杂人像和黑色花色 |

这些素材只用于生成合成碎片和检查接缝评分，不作为正式比赛算法的固定模板库。
